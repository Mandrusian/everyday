# UI harness
`stub.js` stands in for the Rust commands so the interface can be exercised in any browser:

```bash
cp ui/main.js test/main.js && cd test && python3 -m http.server 8790   # then open http://localhost:8790/app.html
```
Checked this way: Today with the briefing, the Gemini buttons including "That was me" (it removes the alert and rewrites the briefing), tasks, an inbox thread with attachments, the assistant with citations, the swipe deck and Settings. This is not a substitute for running on Windows.
